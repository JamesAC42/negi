# Now Playing preferences

Open **Settings → Now Playing** to configure the expanded player. Changes save automatically on this device, independently of the light/dark appearance profiles.

- Left meter, right meter, spectrogram, waveform, and live spectrum can each be hidden.
- Hiding meters leaves more surrounding space while preserving the compact middle sections. The visualizers narrow to the same width as those sections. The waveform, artwork/info, playback controls and spectrogram share aligned edges and form one centered stack with consistent gaps. Desktop windows keep the full stack within the available height: waveform, spectrogram and live spectrum shrink as needed, while playback controls keep their space. Decorative glow does not add a scrollable area. Live spectrum has a responsive preferred height of 12–24rem, capped at 1.5 times the content-sized song-info card; it can shrink further in shorter desktop windows. With live spectrum hidden, the card stays fitted to its content.
- With Waveform off, the playback timeline becomes a simple seek bar. Transport, queue, record player, and lyrics remain available.
- **Album art · dynamic** preserves the existing palette extraction and queue prewarming. **Theme color** inherits the active Appearance accent. **Custom color** accepts a color picker or six-digit hex value, with contrasting control text generated by the existing theme helper.
- Existing compact layouts still hide side meters on narrow screens and the spectrogram on short desktop windows.

Preferences use `music-os:now-playing:v1` in local storage. Missing or invalid fields fall back independently to the original all-visible, album-art-color behavior. Storage failures keep changes active for the current session and show an error in Settings.

npm run typecheck --workspace @music-os/desktop
